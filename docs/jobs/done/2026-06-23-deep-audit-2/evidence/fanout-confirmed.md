## [api-backend/api-1] Login brute-force throttle is defeated by client-spoofable X-Forwarded-For through the Next rewrite proxy
- sev: MEDIUM (corr: ) | kind: defect | cat: security | conf: high
- file: api/routers/private.py:59-71
- WHAT: _client_ip() only honours X-Forwarded-For when the socket peer is a trusted proxy (127.0.0.1/::1), and keys the per-IP rate limit on the first XFF value otherwise on the socket.
